Wrangling Data

Here we load the necessary libraries for this visualisation. We use regular expressions to clean some of the issues in the capacity formatting (some teams have multiple different capacity stadiums). We also assign 20 (worst ranking) for teams who had “no last rank” (they ascended from a different league).

Code 
library(tidyverse)
library(plotly)
library(stringr)
el_basket <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2025/2025-10-07/euroleague_basketball.csv') |> 
  mutate(capacity = str_split(Capacity, ", ")) |> 
  unnest(capacity) |> 
  mutate(capacity = as.numeric(str_replace_all(capacity, ",", ""))) |> 
  mutate(lastrank = as.numeric(str_extract(`Last season`, "\\d+")),
         lastrank = ifelse(is.na(lastrank), 20, lastrank)) |> 
  select(Team, Country, capacity, lastrank, FinalFour_Appearances, Titles_Won, everything())

Ploting Logic

Using plotly…

Code 
el_basket_plot <- el_basket |> 
  mutate(
    team_id = as.numeric(factor(Team)),
    country_id = as.numeric(factor(Country))
  )

el_basket_plot |> 
  plot_ly(
    type = 'parcoords',
    line = list(color = ~country_id, colorscale = 'Rainbow'),
    dimensions = list(
      list(label = 'Team', values = ~team_id, tickvals = unique(el_basket_plot$team_id), 
           ticktext = unique(el_basket_plot$Team)),
      list(label = 'Country', values = ~country_id, tickvals = unique(el_basket_plot$country_id), 
           ticktext = unique(el_basket_plot$Country)),
      list(label = 'Capacity', values = ~capacity),
      list(label = 'Final Four Appearances', 
           values = ~FinalFour_Appearances),
      list(label = 'Titles Won', 
           values = ~Titles_Won),
       list(label = '2024-2025 Rank', 
           values = ~lastrank, 
           range = c(max(el_basket_plot$lastrank, na.rm = TRUE),
                     min(el_basket_plot$lastrank, na.rm = TRUE)))
    )
  ) |> 
  layout(
    autosize = FALSE, width = 800, height = 400,
    margin = list(l = 150, r = 50, b = 10, t = 120),
    title = "EuroLeague Outcomes"
  )

🏀 EuroLeague Outcomes: Interactive Parallel Coordinates Plot

This visualization explores patterns among EuroLeague basketball teams using an interactive parallel coordinates plot. Each line represents a team, connecting its values across multiple performance and contextual dimensions, including country, arena capacity, Final Four appearances, titles won, and the 2024–2025 season ranking.

By dragging along the different coordinate axes, you can highlight or filter specific teams and compare how their attributes align across the variables.

The plot is built using Plotly, making it fully interactive - hover over lines to reveal team details, or select value ranges to focus on subsets of interest. This allows for a dynamic, exploratory look at how success and resources are distributed across Europe’s top basketball clubs.

About this Data

This data comes from Tidy Tuesday

This week we’re exploring EuroLeague Basketball, the premier men’s club basketball competition in Europe.

The dataset contains information on EuroLeague teams, including their country, home city, arena, seating capacity, and historical performance (Final Four appearances and titles won).

The dataset is curated from publicly available sources such as Wikipedia and official EuroLeague records, and was packaged in the EuroleagueBasketball R package, with documentation available at natanast.github.io/EuroleagueBasketball.

“The EuroLeague is the top-tier European professional basketball club competition, widely regarded as the most prestigious competition in European basketball.” - EuroLeague
