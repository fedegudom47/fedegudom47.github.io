Process

Like many things in life, this data vis was not what we originally planned. Our original idea, was to create a spiral plot of histograms, or as this site would call it, condegram.

Our first idea was to turn to the infamous NYT Corona Virus Spiral chart, coincidentally, we found someone who had tried to recreate it in R. This underlying logic was the backbone for this visualisation, that over iterations turned into a quasi-heatmap spiral!

Data Wrangling

Loading the data

Code 
historic_station_met <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2025/2025-10-21/historic_station_met.csv')
station_meta <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2025/2025-10-21/station_meta.csv')

The following chunk defines the number of days in each month and creates month_breaks, a vector marking where each month ends. These breaks are later used as x-axis tick marks for labeling the polar plot by seasons or months.

Code 
month_length <- c(31, 28, 31, 30, 31, 30,
                  31, 31, 30, 31, 30, 31)

month_breaks <- cumsum(month_length) - 30

About this Week!

This week the dataset included data recorded from different UK weather stations starting in 1853 up until 2024. More details about this data set can be found below.

We decided to filter to observations after 2000s in order to enhance interpretability/visibility of the spirals.

Plotting Logic

Rain plot

Code 
rain <- historic_station_met |> 
  filter(station == "heathrow") |> 
  filter(year >= 2000) |> 
  mutate(date = ymd(paste(year, month, "01", sep = "-")),
         day_of_year = yday(date),
         # Handle December specially - extend to end of year instead of next year
         ymd_month = if_else(month == 12, 
                             ymd(paste(year, "12", "31", sep = "-")),
                             date %m+% months(1)),
         day_month = yday(ymd_month)) |> 
  ggplot() +
  geom_segment(aes(x = day_of_year, xend = day_month, 
                   y = date, yend = ymd_month, color = rain), linewidth = 2) +
  scale_color_distiller(palette = "BuPu",
                        direction = 1, 
                        name = "Rainfall (mm)") + 
  geom_label(data = . %>% filter(month == 1, year %% 5 == 0) ,
          aes(x = day_of_year, y = date, label = paste0(as.character(year), "→")),
          hjust = 1, size = 2.5, fontface = "bold",
          alpha = 0.5, fill = "#F5F7FA",
          label.size = NA) + 
  coord_polar() +
  theme_void() +
  scale_x_continuous(minor_breaks = month_breaks, 
                     breaks = month_breaks[c(3, 6, 9, 12)],
                     labels = c("Spring", "Summer", "Autumn", "Winter")) +
  scale_y_continuous(expand = expansion(mult = c(0, 0.1)))+
  theme(
    plot.background = element_rect(color = NA, fill = "#F5F7FA"),
    axis.text.x = element_text(color = "#2C3E50", size = 9, hjust = 10, 
                                family = "playfair", face = "bold"),
    legend.title = element_text(family = "playfair", face = "bold", 
                                size = 11, color = "#2C3E50"),
    legend.text = element_text(family = "playfair", size = 10, 
                               color = "#2C3E50"),
    plot.margin = margin(20, 30, 20, 90)
  )

This visualization juxtaposes monthly rainfall (left) and hours of sunlight (right) recorded at Heathrow, revealing seasonal and long-term weather patterns near London.

In this case, each spiral starts at the center in the year 2000 and extends outward to 2024. Moving clockwise, months progress cyclically around the circle. Colour encodes magnitude with darke blues meaning heavier rainfall and warmer reds meaning more sunlight. Labels mark key years every 5 years so that we can better keep track of the temporal progression.

What we see ☀️

  • Rainfall peaks consistently during the winter months (November–February), while the sunniest months occur in late spring and summer (May–August).
  • The spirals reveal recurring annual rhythms - London’s weather remains relatively stable in its seasonality over the 25-year period.
  • Sunlight hours appear somewhat more variable, with several brighter summers after 2010, possibly reflecting warmer and drier seasons in the last decade.
  • There is no strong long-term drying or wetting trend in rainfall magnitude, though some recent years (post-2018) show slightly drier winters compared to early 2000s.

About this Data

This data was found on the TidyTuesday Repository

The UK Met Office is the United Kingdom’s national weather and climate service, providing forecasts, severe weather warnings, and climate science expertise. It helps people, businesses, and governments make informed decisions to stay safe and plan for the future. It was first established in 1854, making it one of the oldest weather services in the world.

Data has been scraped straight from the Met Office website and cleaned in a basic way. The few flags for “estimated” data and changing sunlight monitoring techniques have been removed for simplicity, but are available from the raw data. Also available is simple site metadata which includes the opening date and latitude and longitude of each station.

Monthly Historical information for 37 UK Meteorological Stations. Most go back to the early 1900s, but some go back as far as 1853. Station data files are updated on a rolling monthly basis, around 10 days after the end of the month. No allowances have been made for small site changes and developments in instrumentation.
